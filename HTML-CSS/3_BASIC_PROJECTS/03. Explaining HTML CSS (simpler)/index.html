Welcome to Web Basics

This is a simplified, easy-to-read guide to understanding the fundamentals of HTML and CSS. No complex tricks, just standard web practices.

1. HTML Document Structure

Every HTML page consists of nested semantic blocks. Here is the standard anatomy of a webpage:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <header>...</header>
    <main>
      <h1>Main Heading</h1>
      <p>Paragraph text goes here.</p>
    </main>
  </body>
</html>

2. The CSS Box Model

Every element in a document is a rectangular box. Understanding how margins, borders, paddings, and contents add up is the core of web styling.

3. Flexbox Layouts

Flexbox is a layout module designed to align and distribute space among items in a container.

Common Properties

  • display: flex;
  • flex-direction: row | column;
  • justify-content: center;
  • align-items: center;
