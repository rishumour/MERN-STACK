# History of JavaScript

JavaScript was created by Brendan Eich in 1995 for the Netscape browser, and it quickly became the core language for adding interactivity to web pages. It was first called Mocha, then LiveScript, and later JavaScript.

In 1996, Netscape and Sun announced JavaScript, and the language was submitted to ECMA International to create a standard. This led to ECMAScript 1 in 1997, which helped make JavaScript consistent across browsers.

## Simple timeline

- 1995: JavaScript is invented by Brendan Eich. 
- 1996: Netscape 2 ships with JavaScript 1.0. 
- 1997: JavaScript becomes standardized as ECMAScript. 
- 1999: ECMAScript 3 is released. 
- 2009: ECMAScript 5 is released. 
- 2015: ECMAScript 6, also called ES2015, brings major modern features. 

## Why it matters

JavaScript started as a small browser scripting language, but it grew into a full programming ecosystem used for front-end, back-end, mobile, and desktop development. Modern JavaScript powers frameworks, server runtimes like Node.js, and many interactive web apps.
